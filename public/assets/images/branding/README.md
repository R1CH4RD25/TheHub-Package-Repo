# Branding Assets

This directory contains custom branding images and logos for the Woodson ISD Maintenance Platform.

## Files:
- `logo.png` - Main platform logo (replaces car icon)
- `logo-small.png` - Small version for mobile/compact views
- `favicon.ico` - Browser favicon

## Usage:
Upload your custom images here and reference them in the code like:
```html
<img src="/assets/images/branding/logo.png" alt="Woodson ISD">
```

## Recommended Sizes:
- Main logo: 200x200px or larger (PNG with transparent background)
- Small logo: 64x64px
- Favicon: 32x32px
