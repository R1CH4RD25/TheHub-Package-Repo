# Student Safety Packages

This directory contains packages related to student safety, welfare, and incident reporting.

## Packages

### 🛡️ Bullying Report v1.0.0
**File:** `bullying-report_1.0.0.hubpkg`

Anonymous bullying incident reporting system for students. Reports are sent to counselors, principals, and administrators for review and action.

**Features:**
- Anonymous submission support
- Comprehensive incident tracking (date, time, location, type)
- Witness tracking
- Multi-step workflow (new → investigating → resolved)
- Role-based access (students submit, counselors manage, principals view stats)
- Built-in statistics dashboard

**Tags:** `safety`, `student-welfare`, `reporting`, `incident-management`

**For:** Students (submit reports), Counselors (manage), Principals (statistics)

**Requirements:**
- Hub >=1.0.0
- PHP >=8.2.0
- MySQL >=10.11.0

---

**Installation:**
1. Admin Dashboard > Package Manager > Search Package Repository
2. Filter by tags: `student`, `safety`
3. Select "bullying-report" and click Install
