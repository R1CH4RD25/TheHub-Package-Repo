# Changelog — Bullying Report

## [1.0.0] — 2025-06-14
### Added
- Initial v3 schema release
- Anonymous incident submission form
- Counselor dashboard with stats cards
- Report detail view with status workflow actions
- Staff notes and assignment management
- Investigation workflow: new → under_review → investigating → resolved/dismissed
- Audit logging for all status transitions
- Multi-select incident types (verbal, physical, social, cyber, etc.)
- Location categorization (classroom, hallway, cafeteria, online, etc.)
- Grade-level reporter identification (optional)
