# Changelog — Vehicle Request Form

## [1.0.0] — 2025-06-14
### Added
- Initial v3 schema release
- Vehicle request submission form with activity details, trip scheduling, passenger info
- Personal request dashboard with stats and request list
- Admin request dashboard with filters, search, export
- Request detail view with approve/deny/cancel actions
- Vehicle assignment workflow for approved trips
- Fleet vehicle management (add, edit, toggle availability)
- Analytics: requests by category, monthly trends, vehicle utilization
- Approval workflow: pending → approved / denied / cancelled
- Audit logging for all state transitions
- Optional integration with Vehicle Maintenance package for fleet data
- Default seed data with 6 district vehicles
